# سجل المناوبات — تطبيق PWA

تطبيق ويب قابل للتثبيت (Progressive Web App) لإدارة دوام المناوبين بنظام **٢٤ ساعة دوام يليها ٣ أيام استراحة**، مع البصمات الأربع، احتساب الساعات الإضافية، وكشف شهري جاهز للطباعة.

## محتويات المجلد

| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق كاملاً (الواجهة + منطق الحسابات + التخزين المحلي) |
| `manifest.json` | بطاقة تعريف التطبيق: الاسم، الأيقونات، شاشة البدء، الاختصارات |
| `sw.js` | عامل الخدمة: يخزّن الملفات ليعمل التطبيق بدون إنترنت |
| `icon-192.png` / `icon-512.png` | أيقونات التطبيق |
| `icon-maskable-512.png` | أيقونة قابلة للقص لأندرويد |

> يجب أن تبقى الملفات الستة في **نفس المجلد**، ولا تُعاد تسميتها.

## شرط أساسي: التشغيل عبر خادم

عامل الخدمة لا يعمل إذا فتحت الملف بنقر مزدوج (`file://`). يحتاج التطبيق إلى **HTTPS** أو **localhost**.

### الخيار ١ — رفع مجاني (الأسهل والموصى به)

**Netlify Drop:** افتح <https://app.netlify.com/drop> واسحب المجلد كاملاً إلى الصفحة. ستحصل على رابط HTTPS خلال ثوانٍ، وافتحه من هاتفك وثبّته.

**GitHub Pages:**
1. أنشئ مستودعاً جديداً وارفع الملفات الستة في جذره.
2. Settings ← Pages ← Source: `main` / `root` ← Save.
3. بعد دقيقة يصبح الرابط: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

### الخيار ٢ — تجربة محلية على حاسبتك

افتح موجّه الأوامر داخل المجلد ثم:

```bash
python -m http.server 8000
```

ثم افتح <http://localhost:8000> في المتصفح.

للتجربة من هاتفك على نفس شبكة الواي فاي: استخدم عنوان الحاسبة مثل `http://192.168.1.10:8000`. الأندرويد يقبل التثبيت من `localhost` فقط، لذلك للتثبيت الحقيقي على الهاتف استخدم الخيار الأول.

## التثبيت على الأجهزة

- **أندرويد (Chrome):** افتح الرابط، ثم اضغط زر **«تثبيت التطبيق»** في أعلى الصفحة، أو من قائمة المتصفح ← «تثبيت التطبيق».
- **آيفون / آيباد (Safari):** زر المشاركة ← **«إضافة إلى الشاشة الرئيسية»**. (يظهر تلميح بذلك داخل التطبيق تلقائياً.)
- **ويندوز / ماك (Chrome أو Edge):** أيقونة التثبيت في شريط العنوان، أو زر «تثبيت التطبيق» داخل الصفحة.

بعد التثبيت يفتح التطبيق بنافذة مستقلة بلا شريط متصفح، ويعمل كاملاً بدون إنترنت.

## البيانات والنسخ الاحتياطي

- البيانات تُحفظ في **ذاكرة المتصفح على الجهاز نفسه** (LocalStorage)، ولا تُرسل إلى أي خادم.
- كل جهاز له نسخته المستقلة. لنقل البيانات: زر **«نسخة احتياطية»** ينسخ ملف JSON، وزر **«استعادة»** يلصقه في الجهاز الآخر.
- حذف بيانات الموقع من المتصفح أو إلغاء تثبيت التطبيق يمسح السجلات، لذا خذ نسخة احتياطية دورية.

## الطباعة

من تبويب **«كشف الساعات»**: اختر الموظف والشهر ثم اضغط **«طباعة الكشف»**. في نافذة الطباعة اختر «حفظ كـ PDF» للحصول على نسخة إلكترونية. الكشف مهيّأ ورقياً مع خانات التواقيع الثلاث.

## قواعد الاحتساب المطبّقة

1. **الدورية:** من تاريخ أول يوم دوام، كل ٤ أيام يوم دوام واحد (٢٤ ساعة) و٣ أيام استراحة.
2. **الوجبة:** أربع بصمات — الصباحية، الوسطية، الليلية، وبصمة صباح اليوم التالي. تُحسب المدة بين البصمة الأولى والرابعة: أول ٢٤ ساعة أساسي، وما زاد **ساعات إضافية**.
3. **يوم الاستراحة:** أي دوام في أيام الاستراحة الثلاثة يُحتسب بالكامل **ساعات إضافية**.

## تحديث نسخة التطبيق

عند تعديل `index.html`، غيّر رقم النسخة في السطر الأول من `sw.js`:

```js
const VERSION = "shift-attendance-v2";
```

هذا يجبر الأجهزة المثبَّتة على سحب النسخة الجديدة عند فتحها التالي.
